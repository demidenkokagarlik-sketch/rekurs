# Аналітичне завдання 1 - Рекурсія

Програма мовою Python, яка послідовно запитує дані для 5 задач і одразу виводить усі результати.

## Що робить програма

1. **Розворот рядка** — приймає рядок і друкує його у зворотному порядку (`"tiger"` → `"regit"`).
2. **Swap nodes in pairs** — міняє місцями кожні два сусідні вузли зв'язаного списку, змінюючи лише покажчики, а не значення (`[1,2,3,4]` → `[2,1,4,3]`).
3. **Числа Фібоначчі** — обчислює `F(n)` за формулою `F(n) = F(n-1) + F(n-2)`.
4. **Сходи** — рахує кількість унікальних способів піднятися на `n` сходів, роблячи 1 або 2 кроки за раз.
5. **pow(x, n)** — власна реалізація піднесення до степеня (включно з від'ємними `n`).

## Як користуватись

Програма по черзі попросить ввести:
- рядок,
- список чисел,
- `n` для Фібоначчі,
- `n` для сходів,
- `x` та `n` для `pow`.

Після цього одразу виведе всі 5 результатів.

## Валідація вводу

Кожен ввід перевіряється згідно з обмеженнями задач:
- Задача 2: 0–100 вузлів, значення 0–100.
- Задача 3: `n >= 0`.
- Задача 4: `1 <= n <= 45`.
- Задача 5: `-100 < x < 100`, `x != 0`, `n` у межах 32-бітного цілого.

На некоректний ввід програма просить повторити лише цей пункт — вона не падає.
